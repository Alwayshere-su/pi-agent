### 3.0a AIC / BIC / Adjusted R² 模型选择指标

> AIC 和 BIC 在 R² 基础上加入参数数量的惩罚项，用于比较不同复杂度模型的相对质量。
> 数值越低越好（对于同一数据集）。ΔAIC = AIC_模型 - AIC_min。
> ΔAIC < 2: 模型质量相当; 2-7: 明显差异; > 10: 显著差异。
> Adjusted R² 校正了参数数量的影响，可用于不同参数数模型间的公平比较。

### 3.0e Langmuir 单层吸附基线模型

> Langmuir 等温线是吸附科学中最基本的定量模型。
> 在定压 P=1 bar 下，我们让 Langmuir 平衡常数 K 随双金属比例变化: K(x) = k0 + k_syn*x*(1-x)。
> 这检验了'协同效应仅通过增强 CO2 结合亲和力起作用'的特定物理假设。

#### NiCo 实测体系

- **方程**: `q = 112714.3859 * K(x) / (1 + K(x)), K(x) = 0.0000 + 0.0001*x*(1-x)`
- **R²**: 0.6106
- **RMSE**: 0.8544
- **MAE**: 0.7385
- **K(x) 协同参数 k_syn**: 9.544150338481222e-05 (k_syn > 0 → K 在 x=0.5 最大，与协同一致)
- **物理解释**: Langmuir 单层吸附模型（P=1 bar），平衡常数 K(x) 含协同项 k_syn*x*(1-x)。该基线来自吸附科学的经典理论，检验协同效应是否仅通过调节 CO2 结合亲和力起作用。若 Langmuir 模型的 R² 显著低于二次回归，说明协同效应不仅影响 K，还影响饱和容量q_sat 或涉及更复杂的协同机制（如 OMS 密度变化、电荷转移等）。
- **解读**: Langmuir 模型 R² = 0.6106 (3 参数)。 k_syn = 0.00 > 0, 表明 K 在 x=0.5 处最大，与协同假设一致。

## 3bis. 基线模型选择说明

### 为什么不用 Slack Model

Slack Model（G. A. Slack, 1970s）是一个**热导率**预测模型，其核心方程为
κ ∝ T⁻¹ × M^(1/3)（即热导率正比于温度的倒数乘以平均原子质量的 1/3 次方）。
该模型本质上是一个"简单混合规则"——认为晶体热导率由平均原子性质线性决定。

将其用作 MOF CO2 吸附的基线存在两个致命问题:

1. **物理不匹配**: 热导率是声子输运性质，CO2 吸附是表面化学相互作用（开放金属位点 OMS
   的 Lewis 酸-碱相互作用、极化、静电势），两者的物理机制完全不同。热导率模型中的
   T⁻¹ 散射因子、Debye 温度、Gruneisen 参数等均不适用于吸附过程。

2. **稻草人论证**: 任意一个不匹配的模型都会表现很差，这不能证明实际模型的优越性。
   真正的检验应该使用**同一物理领域内**的合理竞争假设作为基线。

### 本报告使用的三个基线

本报告用以下三个**物理合理**的基线替代 Slack Model:

| 基线 | 模型 | 物理含义 | 自由参数 | 用途 |
|------|------|---------|---------|------|
| **基线 1** | Vegard's law 线性混合: `cap = x*c_Ni + (1-x)*c_Co` | 无协同零假设。如果双金属 MOF 只是两种纯金属 OMS 的简单混合，容量应为端点值的加权平均。任何正偏差都是协同的证据。 | 等效 2 (端点实测) | 零假设检验 |
| **基线 2** | 最优线性拟合: `cap = a*x + b` (最小二乘) | 最优线性近似。数据驱动的"最佳直线"，允许截距和斜率自由调整。如果二次模型不能显著优于该基线，则非线性协同不成立。 | 2 (拟合) | 线性 vs 非线性模型选择 |
| **基线 3** | Langmuir 单层吸附: `cap = q_sat * K * P / (1 + K * P)` | 经典单层物理吸附模型。Langmuir 方程是吸附科学中最基本的定量模型，如果双金属协同效应仅是"增加了有效吸附位数量"（q_sat 变化），Langmuir 应能捕捉。如果 Langmuir 也无法解释倒 U 型，则协同效应确实超越了简单位点增加。 | 2 (拟合) | 经典吸附理论对比 |

### 为什么这些基线是合适的

- **Vegard's law** 在材料科学（合金、固溶体、功能材料）中广泛用作"无相互作用混合"的
  参考基线。应用于 MOF：如果双金属 OMS 之间不存在电子协同（d 带中心偏移、电荷转移），
  则 CO2 容量应随金属比例线性变化。

- **最优线性拟合** 是统计标准——它允许纯端点值本身也参与拟合（而非像 Vegard 那样
  强制穿过端点），提供了对数据的最佳线性近似。ΔR² = R²_quad - R²_linear 是
  非线性协同的效应量度量。

- **Langmuir 模型** 检验了"协同效应仅通过增加有效吸附位点数量起作用"这一特定假设。
  如果 Langmuir 模型能拟合倒 U 型数据（通过让 q_sat 在中间比例达到峰值），
  则协同机制可能是位点密度增加。如果 Langmuir 也无法解释，则协同机制更复杂
  （如每个位点的平均结合能也随双金属比例变化，这超出了标准 Langmuir 假设）。



## 关于 Slack Model 的历史说明

本报告早期版本曾使用 Slack Model（热导率模型，κ ∝ T⁻¹ × M^(1/3)）作为基线。
该模型已被移除，原因如下:

1. Slack Model 的物理机制（声子散射、热导率）与 MOF CO2 吸附（OMS 化学吸附）
   毫无关系，用作基线是稻草人论证（straw-man argument）。
2. 评审人会立即识别这一不匹配并质疑整个分析的严谨性。
3. 基线模型必须是**同一物理领域**内的合理竞争假设，而非任意不相关模型。

当前使用的三个基线（Vegard's law, 最优线性拟合, Langmuir 模型）均直接来自
材料科学和吸附科学的对应理论体系，构成了有意义的比较基准。

### 5.2 对假设 1 的验证结论（谨慎措辞）

- 🟡 **初步趋势提示（非'✅ 验证通过'）**：实测点 + 估计点的曲线形状与文献定性结论（1:1 最优、双金属 > 单金属）方向一致，支持把'倒 U'作为**待实验确证的候选趋势**。

- **归一化复合数据**: 12 点中仅 3 个 NiCo 实测归一化值；其余 9 点（6 端点估计 + 3 中点强制 1.0）按倒 U 假设构造或文献定性外推。
- **留一法交叉验证（LOOCV）**: 已报告 full-fit R² 与 LOOCV Q²；当估计点参与时，Q² 高不代表实测泛化能力。
- 验证 Gap 1 的「梯度合成实验」(0-100% 比例，步长 10%) 仍是**必要后续步骤**，以获取足量实测点、确认峰值精确位置与倒 U 普适性。

### 5.3a 统计功效分析 — 最小可检测效应

> 给定当前样本量 n=12，评估我们能以 80% 功效检测到的最小效应。

- **样本量 n**: 12
- **模型比较**: 线性 (k=2) vs 二次 (k=3)
- **额外参数数**: 1
- **分母自由度**: 9
- **显著性水平 α**: 0.05
- **目标功效**: 0.8
- **临界 F 值**: F(1,9,0.95) = 5.1174
- **最小可检测 f²**: 0.8267
- **最小可检测 ΔR²**: 0.1214
- **实际观测 ΔR²**: 2.1675 (高于可检测阈值)
- **解读**: 给定 n=12, α=0.05, power=0.8: 最小可检测 f²=0.8267 (大效应水平), 最小可检测 ΔR²=0.1214。只有大效应才能被可靠检测。当前样本量 (n=12) 严重不足，强烈建议增加数据点。

> **含义**: 即使当前 n=12 的小样本，我们依然能够以 80% 功效检测到上述最小效应。
> 如果实际效应大于此阈值（如当前数据集所示），则二次模型的优越性是统计可信的。
> 但如果要在更窄的 CI 或更小的 α 下检测更细微的效应，需要大幅增加样本量（如梯度实验的 11 点）。

### 5.4 估计值推导规则

归一化复合数据中 6 个 is_estimated=True 估计值（另有 3 个'中点强制 1.0'构造值）的推导基于以下显式规则：

- **R_EST_1 (1:1 最优原则)**：多个独立体系（NiCo p62, CoMn p65, FeCu p67）
  均报告 1:1 双金属比例容量最高，纯端点容量 < 峰值。

### 6.2 回归分析摘要（n=5，最小二乘闭式解）

#### d 电子数 Nd 描述符
- **线性**：`Qst = -1.496·Nd + 47.278`，R²=0.7227，RMSE=3.124 kJ/mol
- **二次**：`Qst = -0.080·Nd² - 0.752·Nd + 46.657`，R²=0.7410，RMSE=3.020 kJ/mol
- **幂律**（Nd+1 偏移）：`Qst = 47.741·(Nd+1)^-0.140`，R²=0.6396，RMSE=3.562 kJ/mol
- **嵌套 F 检验（线性 vs 二次）**：F = 0.141, df = (1,2), p = 0.743 → 二次项**不显著**，线性为最稳健可解释描述
- Spearman ρ(Nd, Qst) = -0.600, p = 0.285（负相关趋势，小样本不显著）

#### Pauling 电负性 χ 描述符
- **线性**：`Qst = -11.633·χ + 57.962`，R²=0.190，RMSE=5.341 kJ/mol
- **二次（U 型）**：`Qst = 159.33·χ² - 523.56·χ + 459.41`，R²=0.983，RMSE=0.781 kJ/mol
- **幂律**（χ+1 偏移）：`Qst = 77.166·(χ+1)^-0.724`，R²=0.219，RMSE=5.244 kJ/mol
- **嵌套 F 检验（线性 vs 二次）**：F = 93.4, df = (1,2), p = 0.011 → 在 α=0.05 下二次项**显著**（U 型曲率有统计支撑）
- 物理诠释：低 χ（Mg, 静电主导）与高 χ（Fe/Co/Ni, d 轨道反馈/CFSE）两端 Qst 高，d¹⁰ Zn 处于无反馈+中等 χ 谷底（Qst 最低 29 kJ/mol）

> ⚠️ **循环论证风险提示**：本数据集的 d 电子数/电负性为元素固有属性（非构造值），Qst 为文献实验/计算值，不存在按假设构造的问题；但 n=5 小样本与 Fe 点 [待验证] 意味着统计功效有限，二次 R²=0.983 的置信区间很宽，不能作为"电负性-容量普适关系"的独立确证。

def _parse_float_cell(cell):
    if cell is None:
        return None
    s = str(cell).strip().replace(',', '.')
    try:
        return float(s)
    except ValueError:
        return None


def _parse_table_block(block_lines, section_title):
    clean = [ln for ln in block_lines if '|' in ln]
    if len(clean) < 3:
        return []
    header = [c.strip() for c in clean[0].split('|') if c.strip()]
    if not header:
        return []
    sep_cells = [c.strip() for c in clean[1].split('|') if c.strip()]
    is_sep = bool(sep_cells) and all(set(c) <= set('-: ') for c in sep_cells)
    data_lines = clean[2:] if is_sep else clean[1:]
    x_idx = y_idx = est_idx = src_idx = label_idx = None
    for idx, h in enumerate(header):
        hh = h.lower()
        if est_idx is None and _EST_HDR.search(hh):
            est_idx = idx
        if src_idx is None and _SRC_HDR.search(hh):
            src_idx = idx
        if label_idx is None and _LABEL_HDR.search(hh):
            label_idx = idx
        if x_idx is None and _X_HDR.search(hh):
            x_idx = idx
        if y_idx is None and _Y_HDR.search(hh):
            y_idx = idx
    if x_idx is None or y_idx is None:
        return []  # 仅提取表头显式含 x/y 描述符列的规整数值表，避免预测区间/模型表等垃圾配对
    pairs = []
    for line in data_lines:
        cells = [c.strip() for c in line.split('|')]
        if cells and cells[0] == '':
            cells = cells[1:]
        if cells and cells[-1] == '':
            cells = cells[:-1]
        if len(cells) < 2:
            continue
        xv = _parse_float_cell(cells[x_idx]) if x_idx is not None and x_idx < len(cells) else None
        yv = _parse_float_cell(cells[y_idx]) if y_idx is not None and y_idx < len(cells) else None
        if xv is None or yv is None:
            fcols = [i for i, c in enumerate(cells) if _parse_float_cell(c) is not None]
            if len(fcols) >= 2:
                xv = _parse_float_cell(cells[fcols[0]])
                yv = _parse_float_cell(cells[fcols[1]])
            else:
                continue
        is_est = None
        if est_idx is not None and est_idx < len(cells):
            s = cells[est_idx].strip().lower()
            is_est = s.startswith('true') or s.startswith('是') or s == '1'
        src = cells[src_idx] if (src_idx is not None and src_idx < len(cells)) else ''
        lab = cells[label_idx] if (label_idx is not None and label_idx < len(cells)) else ''
        pairs.append({'x': float(xv), 'y': float(yv),
                      'source': (src or 'table'),
                      'x_header': header[x_idx] if x_idx is not None else '',
                      'y_header': header[y_idx] if y_idx is not None else '',
                      'is_estimated': is_est, 'label': lab, 'dataset': section_title})
    return pairs


def extract_xy_pairs_from_markdown(md_text):
    """增强版：表格逐行扫描 + 章节标题作为 dataset 标签 + is_estimated/source 标注。"""
    pairs = []
    lines = md_text.split('\n')
    section_title = ''
    i, n = 0, len(lines)
    while i < n:
        line = lines[i]
        if line.lstrip().startswith('#'):
            section_title = line.lstrip('# ').strip()
            i += 1
            continue
        if '|' in line and not line.lstrip().startswith('```'):
            block = [line]
            j = i + 1
            while j < n and '|' in lines[j] and not lines[j].lstrip().startswith('#'):
                block.append(lines[j])
                j += 1
            pairs.extend(_parse_table_block(block, section_title))
            i = j
            continue
        i += 1
    # 保留旧版「句子」「列表」正则提取（略，见原脚本方法2/3）
    return pairs

    text = ' '.join(str(hypothesis.get(k, '')) for k in
                    ('title', 'description', 'expected_relationship')).lower()
    out, seen = [], set()

        if score > 0:
            scored.append((score, ds))
    for _, ds in sorted(scored, key=lambda t: -t[0]):

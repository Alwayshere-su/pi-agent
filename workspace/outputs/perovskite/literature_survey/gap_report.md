# 研究空白（Gap）分析报告 — 卤化物钙钛矿带隙与稳定性

> 生成日期：2026-08-02 ｜ 更新日期：2026-08-10（新增 37 篇论文后修订）
> 基础：71 篇钙钛矿论文（arXiv + Semantic Scholar）
> 每条 Gap 标注：类型 / 严重程度 / 置信度 / 证据 / 验证方案

## Gap 1：带隙-稳定性 trade-off 缺乏定量联合描述符
- **类型**：缺失连接（定量关系）｜**严重程度**：高｜**置信度**：0.85（↑ 新增 p50/p57/p65 证据）
- **证据**：
  - p6 (jacs.7b02120)：Sn²⁺ 替代 Pb²⁺ 得窄带隙但稳定性差；Bi³⁺ 替代稳定但带隙大/间接 → "稳定性与光电性能可能互相矛盾"
  - p8 (jacs.6b09645)：阳离子变换设计稳定无铅钙钛矿，但带隙/稳定性未联合量化
  - p34 (mtener.2022.101038)：FASnI3 窄带隙但 Sn²⁺→Sn⁴⁺ 氧化降解严重
  - p14 (anie.202005568)：Cs2AgBiBr6 稳定但带隙 1.72 eV 仍偏大
  - p50 (jpcc.7b00333)：电离能可作为稳定性判据——提供了连续稳定性描述符的可能
  - p65：1221 个双钙钛矿的 E_hull（稳定性）与光学性质并行计算，但未给出联合 trade-off 定律
- **矛盾点**：无任何论文给出"带隙×稳定性"的联合定量框架（如 Pareto 前沿）
- **验证方案**：构建带隙（实验/DFT）与稳定性（分解能/电离能/湿稳定性）联合数据集，检验是否存在普适 trade-off 标度律（可先用表 D 的 8 材料排序做初步回归）

## Gap 2：双钙钛矿间接→直接带隙转变的调控手段缺乏系统性比较
- **类型**：缺失连接｜**严重程度**：高｜**置信度**：0.80（不变）
- **证据**：
  - p8 (jacs.6b09645) / p11 (PhysRevMaterials.2.055401)：间接带隙是双钙钛矿通病，Pb²⁺ 掺杂可致间接→直接转变
  - p1 (1611.05426v2)：Cs2InAgCl6 理论预测直接带隙，但 [待验证]
  - p14 (anie.202005568)：Ag-Bi 无序降带隙 0.26 eV 但未改变带隙类型
  - p70：AgInI4 直接带隙 1.72 eV——In 替代 Bi 或为新的间接→直接路径
- **验证方案**：对同一母体（如 Cs2AgBiBr6）系统比较无序、掺杂、压力、厚度四种手段对"带隙类型+大小"的联合效果

## Gap 3：ML 带隙预测与稳定性预测严重脱节
- **类型**：缺失连接｜**严重程度**：中｜**置信度**：0.80（↑ 新增 p60/p64/p65 证据）
- **证据**：
  - p19 (solener.2021.09.030)：ML 同时预测稳定性和带隙（唯一联合），但论文摘要缺失细节
  - p60：ML 预测带隙 RMSE 21 meV、形成能 RMSE 39 meV/atom——联合预测技术上可行
  - p65：1221 化合物基因组筛选，物理描述符（packing/bonding/polarization/electronic identity）
  - p64：ML 筛选无铅双钙钛矿光伏
  - p2：DFT-1/2 高效带隙预测但未涉及稳定性
- **验证方案**：构建卤化物钙钛矿带隙+分解能联合数据集，训练多任务模型，检验带隙-稳定性的可分离性

## Gap 4：压力/应变-带隙响应的体系间标度关系缺失
- **类型**：未探索空间｜**严重程度**：中｜**置信度**：0.75（不变）
- **证据**：
  - p15 (c9nr07030c)：Cs2AgBiBr6 带隙红移→蓝移（2.3 GPa 相变）
  - p20 (1674-1056/adce9e)：MA2PtI6 带隙单调闭合（0.063/0.079 eV/GPa）
  - 两个体系行为相反，无统一框架解释
- **验证方案**：对系列 ABX3/A2BB'X6 计算压力带隙系数（dEg/dP），检验是否与离子半径/电负性描述符相关

## Gap 5：2D/3D 界面电荷转移对带隙-稳定性的耦合定量缺失
- **类型**：缺失连接｜**严重程度**：中｜**置信度**：0.70（不变）
- **证据**：
  - p33 (acsami.5c00201)：2D/3D 界面电荷转移调带隙+增强稳定性（定性）
  - p5 (commatsci.2022.111649)：MAPbI3/BN 室温稳定（-25 meV@300K），单点证据
  - p55：AVA2FAPb2I7 准 2D 添加剂稳定 CsFAPbI3 晶界（新证据）
- **验证方案**：系统扫描 2D 钙钛矿厚度/有机阳离子链长 × 3D 组分，定量界面电荷转移量与带隙/稳定性的关联

## Gap 6：温度-带隙反常行为（dEg/dT>0）缺乏统一标度与机制归因
- **类型**：矛盾结论（新，2026-08-10 新增）｜**严重程度**：高｜**置信度**：0.78
- **证据**：
  - p36 (PhysRevB.92.201205)：CsSnI3 振动重正化**打开**带隙 0.11 eV@300K / 0.24 eV@500K（dEg/dT>0 反常）
  - p39 (jpclett.9b00876)：铅卤化物带隙随温度**降低**而**降低**（反常），电声耦合主导、热膨胀次之
  - p38/p37：CsPbBr3 非谐振动贡献 450 meV@425K，overdamped 声子机制
  - p49：FAxMA1-xPbI3 温度诱导 gap bowing，FA rattler 模式耦合八面体倾斜
- **矛盾点**：同为卤化物钙钛矿，CsSnI3（打开）、铅卤化物（反常降低）、FA-MA（bowing）的温度响应符号/幅度不同，无统一描述符（如电声耦合常数、rattler 频率）解释
- **验证方案**：系统计算/汇总系列 ABX3 的 dEg/dT 与电声耦合常数（Fröhlich/Allen-Heine 型）、声子频率，检验 dEg/dT 与 rattler/倾斜模式的标度关系

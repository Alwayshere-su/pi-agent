## 五、主要机制链（降解路径）

1. **机械路径**：多晶颗粒 → 晶界裂纹 → 电解液渗透润湿 → 新表面反应 → 表面重构/氧释放 → 阻抗↑容量↓（p06, p24, p31, p32）
2. **化学路径**：深度脱锂 → 表面氧析出 → 阳离子无序（Ni 迁移至 Li 位）→ 层状→岩盐相变 → 容量衰减（p27, p32）
3. **全电池路径**：循环 → 锂库存损失（SEI 再生长 + 阳极活性损失）→ 可用容量↓（p28）
4. **单晶路径**：单晶内位错滑移 → 裂纹萌生（无晶界缓解）→ 但化学降解仍存在（Ni 价态异质性）（p25, p24）
5. **界面工程路径（新）**：高压循环 c 晶格收缩 → 界面退化 → CEI 添加剂（3-Thp-BOH）/ 过锂化 / 限压 / 涂层优化（1.5 wt% 火山峰值）缓解 → 寿命倍增（p43, p44, p46）
6. **质子诱导路径（新）**：水洗除杂 → 近表面 Li⁺/H⁺ 交换 → 质子残留 → 衰减与阻抗随质子含量↑（p48）

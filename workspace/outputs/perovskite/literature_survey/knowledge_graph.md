## 二、关键性质与数值

- **带隙计算方法**：
  - DFT-1/2 方法达到 GW 精度（p2）；HSE 混合泛函 + 线性 exact-exchange 随 Br 含量增（p4/p52）；VCA 虚拟晶体近似遵守 Vegard 律（p13）
  - 有限温度带隙：范围分离杂化泛函 + SOC 校正 + special displacement 法（零点振动），MAE 0.17 vs 实验（p46）
  - ML 预测双钙钛矿带隙（p41）；495 个 ABX3 高通量 DFT 数据集（p53）；1221 个 A2BB'X6 描述符框架（p65）
- **带隙调控手段**：
  - Ag-Bi 无序增强可降 Cs2AgBiBr6 带隙 ~0.26（最小 1.72）（p14）
  - 压力诱导相变：Cs2AgBiBr6 NC 在 2.3 立方→四方，带隙红移→蓝移（p15, c9nr07030c）
  - MA2PtI6 压力下带隙闭合速率 0.063/0.079/GPa（1.2 前后）（p20, 1674-1056/adce9e）
  - 厚度调控 2D Cs2AgBiBr6 带隙（p16, d0cp03919e）
  - 阳离子变换 2Pb²⁺→M⁺+M³⁺ 设计无铅无机钙钛矿（p8, jacs.6b09645）
  - Cu-In 卤化物钙钛矿 CIGS 式电子结构设计（p6, jacs.7b02120）
  - MAPbI3 单层在 BN 单层上室温稳定（-25@300），带隙 ~1.6，吸收系数 4.9×10⁴ cm⁻¹@2.8（p5, commatsci.2022.111649）
  - 卤素渐进替换：K2SnGeX6 带隙 2.44（Cl）→0.64（I）（p66）
  - 过渡金属钙钛矿硫族化物带隙从远红外到 UV 可调（p47）
- **温度-带隙行为（关键新证据）**：
  - CsSnI3 带隙随振动重正化**打开**：0.11@300 / 0.24@500（p36）——温度升高带隙增大（反常 dEg/dT>0）
  - CsPbBr3 非谐振动贡献达 450@425，带隙随温度"温和变化"（p38）；overdamped 声子主导（p37）
  - 铅卤化物钙钛矿带隙随温度降低而**降低**（反常温度依赖），高压实验分离热膨胀 vs 电声耦合（p39, jpclett.9b00876）
  - FAxMA1-xPbI3 温度诱导 gap bowing：电子-声子耦合为主导项，FA rattler 模式耦合八面体倾斜（p49）
- **稳定性机制**：
  - 内禀局域畸变（polymorphous networks）vs 动态热运动：畸变不随时间平均为零，决定带隙与稳定性（p3, mattod.2021.05.021; p10, PhysRevB.101.155137; p56）
  - 离子迁移决定长期稳定性（p12, D0TA03200J）
  - 2D/3D 界面电荷转移增强稳定性不损效率（p33）
  - **电离能作为稳定性判据**：分解反应焓与电离能关联，容差因子/八面体因子不足以预测（p50, jpcc.7b00333）
  - ML + DFT 分解能计算稳定性（p51）；Cs1-xRbxPbI3 化学分解第一性原理热力学（p57）
  - AVA2FAPb2I7 准 2D 添加剂稳定 CsFAPbI3 晶界，抑制热循环相变（p55）
- **ML/高通量**：
  - ML 同时预测带隙+稳定性：RMSE 21（带隙）、39/atom（形成能）（p60）
  - 基因组引导筛选：1221 个 A2BB'X6，凸包 E_hull ≤ 0/atom，吸收峰 ~1e5（p65）
  - ML 筛选无铅双钙钛矿（p64）；氧化物钙钛矿 ML 稳定性（p59）

## 五、已知矛盾与不确定点

1. Cs2AgBiBr6 带隙报告范围 1.72-1.98，来源差异大（合成质量/无序度依赖）——p14 vs p17
2. 双钙钛矿普遍间接带隙 vs 太阳能电池需要直接带隙——存在根本矛盾（p8/p11）
3. 压力带隙行为：Cs2AgBiBr6 红移→蓝移（p15）vs MA2PtI6 单调闭合（p20）——机制不同
4. Sn 基窄带隙（好）但氧化不稳定（坏）vs Bi 基稳定（好）但带隙大/间接（坏）——带隙-稳定性 trade-off 无定量框架
5. **温度-带隙反常行为普遍但无统一标度**：CsSnI3 振动打开带隙（dEg/dT>0，p36）；铅卤化物带隙随 T 降低而降低（p39）；FA-MA 混合阳离子 gap bowing（p49）——三者的 dEg/dT 符号与幅度差异缺乏统一描述符解释
6. 稳定性判据多元：容差因子/八面体因子（p66 仍用）、电离能（p50）、分解焓（p51/p57）——孰优孰劣未系统比较

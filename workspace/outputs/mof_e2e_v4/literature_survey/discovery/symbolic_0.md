## 遗传编程结果（过拟合警示）

轻量遗传编程在 n=5 小样本上达到 R²=1.0000，但表达式含 sin/log/sqrt 等复杂算子组合，
**为典型过拟合**（自由度远超 5 个数据点的信息量），不具备物理可解释性与外推能力。
**结论：小样本下通用符号回归不可靠，改用物理驱动的受限表达式。**

## 可解释表达式（quant_validate_v4.py，受限模型）

### 高斯峰模型（推荐，4 参数）
```
C(x) = 5.595·exp(-(x-0.369)²/(2·0.194²)) + 3.781
R² = 0.9778 | RMSE = 0.256 mmol/g
```
- **最优组分 μ = 0.369（偏离名义 1:1 的 x=0.5）**：Ni 富集侧容量衰减更快
- 协同增益 A = 5.60 mmol/g（相对基线 B = 3.78）
- 峰宽 σ = 0.194（约 ±0.39 组分区间内协同有效）

### 二次多项式（3 参数，次优）
```
C(x) = 5.115 + 11.796·x - 13.799·x²
R² = 0.7694 | RMSE = 0.823 mmol/g
```

### 经典线性混合（Vegard 类比，基线）
```
C(x) = 6.470 - 2.003·x
R² = 0.2075 | RMSE = 1.525 mmol/g
```

## 结论

- **ΔR²（高斯 vs 线性混合）= +0.770**：双金属倒U 远优于经典线性混合规则
- 高斯 4 参数 vs 线性 2 参数：嵌套 F 检验 F=17.3（n=5 小样本，p=0.17 未达显著，但 ΔR² 巨大且 BIC 从 7.44 → -7.21 强支持高斯）
- **科学含义**：Ni/Co 双金属 OMS 协同在 x≈0.37 达最优——Co 侧富 Ni 提升容量（Ni 高 Qst），但 Ni 侧富 Co 反而降低（Co 低 Qst + 配位构型变化），倒U 不对称
- **外推预测**：模型预测 Ni0.37Co0.63-MOF-74 容量 ~9.4 mmol/g（0℃, 1bar），建议实验合成验证（配分非理想，Xu v3s1 固态 NMR 支持非随机配分）

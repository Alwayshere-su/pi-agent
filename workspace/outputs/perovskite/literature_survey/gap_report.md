# 研究空白（Gap）分析报告 — 卤化物钙钛矿带隙与稳定性

> 生成日期：2026-08-02 ｜ 基础：34 篇钙钛矿论文（arXiv + Semantic Scholar）
> 每条 Gap 标注：类型 / 严重程度 / 置信度 / 证据 / 验证方案

---

## Gap 1：带隙-稳定性 trade-off 缺乏定量联合描述符
- **类型**：缺失连接（定量关系）｜**严重程度**：高｜**置信度**：0.85
- **证据**：
  - jacs.7b02120：Sn²⁺ 替代 Pb²⁺ 得窄带隙但稳定性差；Bi³⁺ 替代稳定但带隙大/间接 → "稳定性与光电性能可能互相矛盾"
  - jacs.6b09645：阳离子变换设计稳定无铅钙钛矿，但带隙/稳定性未联合量化
  - mtener.2022.101038：FASnI3 窄带隙但 Sn²⁺→Sn⁴⁺ 氧化降解严重
  - anie.202005568：Cs2AgBiBr6 稳定但带隙 1.72 eV 仍偏大
- **矛盾点**：无任何论文给出"带隙×稳定性"的联合定量框架（如 Pareto 前沿）
- **验证方案**：构建带隙（实验/DFT）与稳定性（分解能/氧化电位/湿稳定性）联合数据集，检验是否存在普适 trade-off 标度律

## Gap 2：双钙钛矿间接→直接带隙转变的调控手段缺乏系统性比较
- **类型**：缺失连接｜**严重程度**：高｜**置信度**：0.80
- **证据**：
  - jacs.6b09645 / PhysRevMaterials.2.055401：间接带隙是双钙钛矿通病，Pb²⁺ 掺杂可致间接→直接转变
  - 1611.05426v2：Cs2InAgCl6 理论预测直接带隙，但 [待验证]
  - anie.202005568：Ag-Bi 无序降带隙 0.26 eV 但未改变带隙类型
- **验证方案**：对同一母体（如 Cs2AgBiBr6）系统比较无序、掺杂、压力、厚度四种手段对"带隙类型+大小"的联合效果

## Gap 3：ML 带隙预测与稳定性预测严重脱节
- **类型**：缺失连接｜**严重程度**：中｜**置信度**：0.78
- **证据**：
  - solener.2021.09.030：ML 同时预测稳定性和带隙（唯一联合），但论文摘要缺失细节
  - s41598-017-14435-4：DFT-1/2 高效带隙预测但未涉及稳定性
- **验证方案**：构建卤化物钙钛矿带隙+分解能联合数据集，训练多任务模型，检验带隙-稳定性的可分离性

## Gap 4：压力/应变-带隙响应的体系间标度关系缺失
- **类型**：未探索空间｜**严重程度**：中｜**置信度**：0.75
- **证据**：
  - c9nr07030c：Cs2AgBiBr6 带隙红移→蓝移（2.3 GPa 相变）
  - 1674-1056/adce9e：MA2PtI6 带隙单调闭合（0.063/0.079 eV/GPa）
  - 两个体系行为相反，无统一框架解释
- **验证方案**：对系列 ABX3/A2BB'X6 计算压力带隙系数（dEg/dP），检验是否与离子半径/电负性描述符相关

## Gap 5：2D/3D 界面电荷转移对带隙-稳定性的耦合定量缺失
- **类型**：缺失连接｜**严重程度**：中｜**置信度**：0.70
- **证据**：
  - acsami.5c00201：2D/3D 界面电荷转移调带隙+增强稳定性（定性）
  - commatsci.2022.111649：MAPbI3/BN 室温稳定（-25 meV@300K），单点证据
- **验证方案**：系统扫描 2D 钙钛矿厚度/有机阳离子链长 × 3D 组分，定量界面电荷转移量与带隙/稳定性的关联

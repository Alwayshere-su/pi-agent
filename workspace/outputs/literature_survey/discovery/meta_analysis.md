# 跨体系 meta-analysis：双金属 MOF 协同峰相对 Vegard 线性内插基线的增强率

> 问题 #10 残余专项：NiCo-MOF-74 单体系实测点仅 3 个（x=0/0.5/1.0），单体系曲线拟合自由度不足。本文不拟合任何单体系曲线，改为 meta-analysis 跨体系口径：以每个双金属体系中点（协同峰）相对 Vegard 线性内插基线（两端点算术平均，无协同零假设）的增强率作为统一效应量，跨体系做推断统计。

## 1. 方法

- **Vegard 基线（无协同零假设）**：若双金属 MOF 仅是两种单金属 OMS 的简单混合，容量应随比例线性内插。在中点 x=0.5 处，期望值 `linear_mid = (endpoint_low + endpoint_high) / 2`。
- **效应量**：`ratio = (mid_value - linear_mid) / linear_mid`，即中点评实测/估计值相对线性内插的**相对增强率**。
- **跨体系推断**：单样本 t 检验（H0: 平均增强率 = 0，双侧），95% CI，Cohen's d（单样本 d = mean/std），符号检验（正向体系占比，二项检验 H0: p=0.5）。
- **样本量门槛**：体系数 n<4 时 t 检验不适用（自由度不足），仅报告符号检验并显式注明。
- **数据来源**：数值全部来自 `quantitative_pairs.json`、`quantitative_validation.md` 表1.1/1.2（§4bis 推导规则）、`knowledge_graph.md`；实测/估计逐条标注，未编造任何文献数值。

## 3. 统计结果

- **纳入体系数 n** = 4（其中中点实测 1 个，中点归一化估计 3 个）。

- **平均增强率** = 61.3%，样本标准差 = 22.5%，标准误 = 11.2%。
- **单样本 t 检验（H0: 平均增强率=0）**：t = 5.46，df = 3，p = 0.0121（双侧）。
- **95% CI（平均增强率）** = [25.5%, 97.0%]，不包含 0，在 α=0.05 下显著。
- **Cohen's d（单样本）** = 2.73（大效应）。
- **符号检验**：4/4 个体系增强率为正（100%），二项检验 p = 0.1250（双侧，H0: p=0.5）。

## 4. 物理诠释

- **正向协同在全部 4 个纳入体系中一致出现**：4/4 个体系中点高于两端点线性内插（Cu/Mg s-d 单调增反例因无中点且条件不可比被排除）。
- **增强幅度体系依赖**：
  - NiCo-MOF-74：84%（实测）
  - FeCu-MOF：74%（归一化估计）
  - CoMn-MOF-74：54%（归一化估计）
  - MIL-101(Cr,Mg)：33%（归一化估计）
  —— 与 OMS 型 MOF-74 平台（d-d 组合、开放式金属位点密集）协同幅度大于介孔 MIL-101 框架的物理预期一致（R5/R19：曲线形状与幅度依赖金属组合与框架）。
- **机理旁证**：d-d 组合（NiCo/CoMn）倒 U、s-d 组合（Cu/Mg）单调（R19），电子结构（d 带中心差/空反键轨道，R27）是协同的来源；meta-analysis 给出的正增强率与 R5「双金属比例→容量非单调、存在体系依赖峰值」方向一致。

## 5. 与单体系拟合的关系

- **单体系口径（quantitative_validation.md）**：NiCo 全 8 点（3 实测+5 估计）二次拟合R²=0.6919，嵌套 F=9.909, p=0.0254，峰值 x=0.437；但**仅实测点 3 点**自由度=0，二次 R²=1.0 是数学恒等，不能作为统计证据。
- **meta-analysis 口径（本文）**：不拟合任何单体系曲线，把每体系中点增强率作为独立效应量跨体系检验。NiCo 实测中点增强率 84.0%（8.300 vs 4.510 mmol/g）与单体系二次拟合峰值增强 +83%（8.32 vs 4.55）几乎一致，两口径相互印证；且 meta 口径把「自由度问题」从单体系拟合参数数（3 点 3 参数）转移为跨体系样本量（4 个独立体系），可做 t 检验/符号检验。
- **代价**：4 个体系中 3 个为归一化估计（中点=1.0 为构造值），若排除它们则只剩 1 个体系，统计口径将退化为单体系，无法做跨体系推断。因此本文结果**只能定性支持「正向协同」的普适趋势，不能定量确证倒 U 普适性**。

## 6. 局限与诚实声明

- 数值全部来自真实文件（quantitative_pairs.json / quantitative_validation.md / knowledge_graph.md），无编造；is_measured 逐条标注。
- CoMn/FeCu/MIL-101 的端点与中点为归一化估计（§4bis R_EST 规则 + 文献定性结论），`中点=1.0` 含归一化构造成分，**仅趋势参考，不替代实验验证**。
- n=4 样本量仍小：t 检验功效有限（按 quantitative_validation.md §5.3a 的经验，n=12 时才仅能检测大效应）；符号检验 p=0.1250（双侧）本身不显著，显著性主要由 4/4 全正向 + t 检验贡献。
- 各体系测试条件不完全一致（NiCo 298K/1bar；FeCu 1-5 bar/40-50°C 系统评估；MIL-101 条件见 p147），但效应量是体系内归一化/同条件端点内插，跨体系比较基于「增强率」而非绝对容量，条件差异影响有限。

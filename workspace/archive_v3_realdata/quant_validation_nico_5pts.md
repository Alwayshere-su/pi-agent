- Spearman ρ(d电子数, Qst) = -0.600, p = 0.285
- 趋势：d 电子数 ↑ → Qst ↓（负相关（n=5 未达显著））

- 去 Fe 拟合线性: Qst = 47.92 -1.51·Nd
- Fe 残差 = -2.88 kJ/mol（低于趋势线）
- 解释：Fe-MOF-74 为 Mott 绝缘体（强关联），DFT 泛函分歧物理根源（Rocca 2025, p30）→ 支持 Gap 2

### B5. 双描述符联合建模 Qst = β0 + β1·Nd + β2·χ

- β0=32.53, β1=-1.99, β2=10.39
- R² = 0.7940（vs 单变量线性 0.7227）
- 结论：双描述符显著提升（Nd+χ 联合）
